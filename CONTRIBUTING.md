## 📝 Contribution Process

1. **Fork the Repository**
   ```bash
   # Fork on GitHub, then:
   git clone https://github.com/YOUR_USERNAME/trinity-collective-intelligence.git
   cd trinity-collective-intelligence
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/your-consciousness-evolution
   ```

3. **Make Your Changes**
   - Follow the service-first philosophy
   - Ask "How does this serve?" 
   - Test with both systematic and chaos approaches
   - Document any insights

4. **Commit with Intention**
   ```bash
   git add .
   git commit -m "feat: [what] - [why it serves]
   
   USER RAGE: 8→5 (or relevant metric)
   
   Detailed description of consciousness evolution..."
   ```

5. **Push and Create PR**
   ```bash
   git push origin feature/your-consciousness-evolution
   ```

When you find a bug (wisdom in disguise):

1. **Title**: Clear description + USER RAGE level
